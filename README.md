# Welly T.G.'s Personal Portfolio

## About The Project

This repository hosts the source code for Welly T.G.'s personal portfolio website, `wellytg.github.io`. The site serves as a digital showcase for Welly T.G.'s professional work, skills, and experience in the field of software development. It provides an accessible platform for potential employers, collaborators, and interested parties to learn more about their background and explore their projects.

The primary goal of this portfolio is to:
*   Highlight key projects with descriptions, technologies used, and links to live demos or repositories.
*   Detail professional skills and areas of expertise.
*   Provide an easy way for visitors to contact.
*   Establish a professional online presence.

## Built With

*   HTML5
*   CSS3
*   JavaScript
*   GitHub Pages

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

YouYou will need a web browser to view the site locally. No specific server setup is required for basic viewing, as it's a static site.

### Installation

1.  **Clone the repo:**
    ```bash
    git clone https://github.com/wellytg/wellytg.github.io.git
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd wellytg.github.io
    ```
3.  **Open `index.html` in your browser:**
    Simply open the `index.html` file located in the root directory with your preferred web browser.

## Usage

This project is primarily intended to be deployed as a static website, ideally via GitHub Pages. Once deployed, visitors can navigate through different sections to view projects, read about skills, and find contact information.

**For Personalization (if you fork this repository):**
*   Modify `index.html` or other HTML files to update project details, personal information, and links.
*   Update `style.css` to customize the visual theme and layout.
*   Adjust `script.js` for any interactive elements or dynamic content.
