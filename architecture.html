Production Isolation

A strict "Prod-Only" remote strategy ensures that internal development context (prompts, thinking logs, agent history) never leaks to public repositories.

  • Local-only artifacts are git-ignored at the root.
  • Public repos contain only production code and high-level architecture docs.
